Automatic doors that open too late, phones that ring in meetings, updates that pop up mid-presentation. These awkward moments happen because tech often demands too much attention or acts without context.

How to cope with it? The answer is implicit interactions. And its framework is:

Attentional demand (foreground vs. background)

Initiative (user-initiated vs. system-initiated)

Additionally, using interaction patterns that is similar with human behavior can be more polite and context-aware

What's the purpose of the capacitor here?

Think of a capacitor as a backup battery for current. Whenever the servo suddenly demands a surge of power, the capacitor steps in to supply it. This keeps the Arduino from experiencing a voltage drop that could otherwise cause crashes or unwanted resets.

Whenever the component may cause rapid current changes, it is strongly recommended to add capacitors.

The function "millis()" is a built-in Arduino function that returns the elapsed time (in milliseconds) since the Arduino was powered on. It's like a clock. 

#include "Servo.h"

Servo servoMotor; // Using the class "Servo" from the "Servo.h" library, and I customized an object called "servoMotor".

const int inputPin = A0;
const int outputPin = 2;

int inputValue = 0;
int outputServoAngle = 0;

long lastMoveTime = 0;

void setup() {
  Serial.begin(9600);
  pinMode(inputPin, INPUT);
  pinMode(outputPin, OUTPUT);
  servoMotor.attach(outputPin);
}

void loop() {
  inputValue = analogRead(inputPin);
  Serial.println(inputValue);

  outputServoAngle = map(inputValue, 0, 1023, 0, 179);

  if(millis() - lastMoveTime > 20) {
    servoMotor.write(outputServoAngle);
    lastMoveTime = millis(); // Servo angle updates are only permitted once every 20 milliseconds.
  }
}

A Musical Instrument
#include "pitches.h"

const int threshold = 30;  // Determination of whether I pressed the FSR. When it is too low, the FSRs will be easily considered pressed and there will be tons of tones flickering even I was not pressing the FSRs with my hand.
const int speakerPin = 2;
const int noteDuration = 20;

int notes[] = {NOTE_C4, NOTE_B4, NOTE_B5};

void setup() {

}

void loop() {
  for(int thisSensor = 0; thisSensor < 3; thisSensor++) {
    int sensorReading = analogRead(thisSensor);

    if(sensorReading > threshold) {
      tone(speakerPin, notes[thisSensor], noteDuration); //which outpin, tone, time.
    }
  }
}
