Lab 01-Transistor

A DC Motor

At the very beginning, the motor just kept spinning nonstop — there was no “blinking” effect at all. After poking around for a while, I realized the issue: I had flipped the diode the wrong way. Out of habit, I connected the diode’s anode to the collector and the cathode to the emitter, just like I usually did with other components. Later it hit me — the diode’s actual job here is to block the current from passing through. Which means, of course, it should have been reversed.

const int transistorPin = 9;
int transistorValue;
const int potentiometerPin = A0;
int potentiometerValue;

void setup() {
  Serial.begin(9600);
  pinMode(potentiometerPin, INPUT);
  pinMode(transistorPin, OUTPUT);
}

void loop() {
  potentiometerValue = analogRead(potentiometerPin);
  transistorValue = map(potentiometerValue, 0, 675, 0, 255);
  analogWrite(transistorPin, transistorValue);

  Serial.println(potentiometerValue);
  Serial.println(transistorValue);
}
A LED Lamp

I just wanna have a try so I borrowed this machine from the shop.

1. Is this light bulb DC or AC? If it’s DC, how do I check the polarity? I wired it randomly without paying attention to polarity, and it still lit up. Does that mean the bulb is actually AC? But then my classmate told me that this machine can only supply DC.

2. I wired up the circuit, but when I turned on the power, the bulb didn’t light up. To double-check, I used serial.println to monitor the code—Arduino’s inputs and outputs were fine. Then I tested the bulb and the power supply: when I bypassed the transistor and connected the bulb directly to the power source, it lit up. That confirmed the problem had to be with the transistor. So I went to the shop and got another MOSFET transistor. With the new one, the circuit worked perfectly. Now I’m curious—what’s the difference between these two models? (The first one, above, didn’t work; the second one, below, did.)

Figure it out in the class:

1. Socket on the wall/power strip: AC ---- (AC to) DC power supply ---- bulb socket: DC without polarity (by design) ---- bulb: DC

2. The former MOSFET should have worked because theoretically transistors with higer values should be more versatile. It is possible that this specific MOSFET is broken.

const int switchPin = A0;
const int motor1Pin = 3;
const int motor2Pin = 4;
const int pwmPin = 5;  

void setup() {
  pinMode(switchPin, INPUT); 
 
  pinMode(motor1Pin, OUTPUT);
  pinMode(motor2Pin, OUTPUT);
  pinMode(pwmPin, OUTPUT);
 
  analogWrite(pwmPin, 100);

}

void loop() {
  // if the switch is high, motor will turn on one direction:
    if (digitalRead(switchPin) == HIGH) {
      digitalWrite(motor1Pin, LOW);   // set leg 1 of the motor driver low
      digitalWrite(motor2Pin, HIGH);  // set leg 2 of the motor driver high
      
    }
    // if the switch is low, motor will turn in the other direction:
    else {
      digitalWrite(motor1Pin, HIGH);  // set leg 1 of the motor driver high
      digitalWrite(motor2Pin, LOW);   // set leg 2 of the motor driver low
    }
}

Figure it out in the class:

The schematic on the webpage is kinda wrong from the acutual wiring. The power jack doesn't directly supply the VM pin on the H-bridge. It supplies the VM pin through the microboard (VIN pin in and 5V pin out).
