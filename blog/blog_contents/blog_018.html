Problem 2 is solved by changing the servo and altering the random function in the code (A0 noise→randomSeed(micros());).

The new code:

#include   // 引入舵机控制库

Servo servoScissors;
Servo servoRock;
Servo servoPaper;

const int trigPin = 7;
const int echoPin = 8;

const int TRIGGER_DIST = 10;
const int PUNCH_HOLD_TIME = 1000;

void setup() {
  Serial.begin(9600);

  servoScissors.attach(2);
  servoRock.attach(3);
  servoPaper.attach(4);

  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);

  resetServosTo0();

  randomSeed(micros());
}

void loop() {
  float currentDist = getUltrasonicDist();

  Serial.print("距离: ");
  Serial.print(currentDist);
  Serial.println(" cm");

  if (currentDist > 0 && currentDist < TRIGGER_DIST) {
    int randomChoice = random(3);  // 生成0-2的随机数

    switch (randomChoice) {
      case 0:
        servoScissors.write(90);
        Serial.println("Scissors");
        break;
      case 1:
        servoRock.write(90);
        Serial.println("Rock");
        break;
      case 2: 
        servoPaper.write(90);
        Serial.println("Paper");
        break;
    }

    delay(PUNCH_HOLD_TIME);
    resetServosTo0();
    delay(500);
  }
}

void resetServosTo0() {
  servoScissors.write(0);
  servoRock.write(0);
  servoPaper.write(0);
}

float getUltrasonicDist() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long echoTime = pulseIn(echoPin, HIGH, 20000);
  if (echoTime == 0) return -1;
  return echoTime / 58.0;
}

2025-10-08

We booked the office hour with Mr. Igeo and we got the answers to our questions.

1. Current battery is 3V not enough for everything. We need a battery 6_9V.

2. Because we need to solder the bridge on the back of the 5V pin of Nano 33 Iot otherwise it wouldn’t work.

3. The Nano 33 Iot can only output 3.3V even we soldered the 5V pin and used it as an current output pin (by the built-in regulator inside the Nano 33 Iot). Therefore, when we put a large voltage into Vin pin, the regulator on the board is overloaded. That's why we had a super hot board.

4. And Mr. Igeo suggested us supply all the things with just battery.

Then we transfered the Nano board from a breadboard to an adapter hoping to get a larger volatge. But it was still limited under 3.3V.

We are now pretty sure now that we need to break through this limit.

2025-10-11

To solve the issue, we decided to give up on the red adapter and use only the breadboard. The sensor and servos were powered by a 6V battery pack, while the Nano ran on a 4.5V battery pack—two separate power sources.
