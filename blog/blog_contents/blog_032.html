2025-11-05

We emailed Tom and got his suggestion: "I think the main thing missing from this is any form of sustained interaction. I could put a sacred offering on the plate or an old shoe on the plate, and either one would receive the same reward. Perhaps think about what you can do with the interaction that encourages the participant to continue paying attention, observing, reflecting, praying, or whatever behavior you are trying to inspire. Perhaps they have to remain in a pose that you are sensing? Continue a chant or a movement? Maintain the state of a sacred object, e.g. hold it upright when its resting position is horizontal? Continue a series of actions, like touching a number of holy stones in sequence, or at a given pace? All of these are examples of sustained interaction. Think about how you can make your project something we continue to work with, rather than activate, then passively watch, or worse, activate, then ignore."

According to Tom, we improved our interaction design:

Instead of placing an object on a plate, users will now hold a single fortune stick for several seconds to “convey” their wish to Guanyin. We plan to detect this sustained contact with a temperature sensor. This turns the ritual into a focused, time-based action rather than a one-time trigger. Fortune sticks are traditionally used for divination in Chinese temples. Seekers silently pose a question or wish, and then ask for the explanation for the text or number on their stick to receive guidance from the god.

Arduino code: Read sensor readings to three decimal places.

const int TMP36_PIN = A0;
const float ADC_REF_VOLT = 3.3;
unsigned long lastSend = 0;
float tempC = 0;

void setup() {
  Serial.begin(9600);
  analogReadResolution(12);      // 提升到 12-bit 精度（0–4095）
  pinMode(TMP36_PIN, INPUT);
}

void loop() {
  // 采样并换算温度
  int adc = analogRead(TMP36_PIN);
  float voltage = adc * (ADC_REF_VOLT / 4095.0f);
  tempC = (voltage - 0.5f) * 100.0f;

  // 每隔 1 秒发送一次，保留三位小数
  if (millis() - lastSend >= 1000) {
    lastSend = millis();
    Serial.print("TEMP:");
    Serial.println(tempC, 3);
  }

  delay(50);
}

const int FSR_PIN = A0;
unsigned long lastSend = 0;

void setup() {
  Serial.begin(9600);
  pinMode(FSR_PIN, INPUT);
}

void loop() {

  int adc = analogRead(FSR_PIN);

  // 每秒发送
  if (millis() - lastSend >= 1000) {
    lastSend = millis();
    Serial.println(adc);
  }

  delay(10);
}
