But basically (in almost every project if I am not working with an human programmer), I asked LLM to generate the initial code under the demands formed by my system design. Sometimes I talk with LLM to specify my system design. Then I will change manually some details of the code and ask LLM to memorize it. If I encounter any bugs, I will let LLM to fix them. And if LLM cannot solve the problem. I will manually do the debug.

I feel like this workflow is pretty efficient for me when working alone since I do not recognize myself as a programmer. I just need to understand the basic logic of the code and the command lines.
