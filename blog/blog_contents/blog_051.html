1-Project Summary

The watering device is a project that is a webpage that monitors the soil moisture levels of one of my houseplants in real time. An Arduino reads the soil moisture, connects to a virtual machine via my home Wi-Fi, and then the virtual machine transmits the data to the web page. The Arduino sends data once per hour.
